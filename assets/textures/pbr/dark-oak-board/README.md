# Dark oak furniture board

New albedo generated with imagegen for CENTRUM. An artistic dark woodgrain
melamine finish, not a scan or exact reproduction of a named commercial decor.
Vertical grain, nominal 1 m field. World-space box mapping maintains the vertical
direction on the straight and rounded walls. Roughness and shallow embossing
are shader approximations from this albedo, not measured PBR data.

Material recipe: `tools/dark_board_blender.py`.
